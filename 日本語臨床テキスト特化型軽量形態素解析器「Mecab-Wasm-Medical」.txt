1. 日本語臨床テキスト特化型形態素解析器「Mecab-Wasm-Medical」
技術的特性:

WebAssembly（Wasm）バイナリとしてコンパイルされ、ブラウザ/WebViewのサンドボックス環境単体で動作。

Minds診療ガイドライン用語集およびICD-10（国際疾病分類）対応辞書を内包しながら、辞書圧縮技術等によりフットプリントを極小化。

0.5ms/クエリという超低レイテンシで病名・処方・症状等のトークン分割・正規化・エンティティ抽出が可能。

臨床現場における意義:

外部サーバー通信（クラウドAPI）を一切行わずにクライアントサイドで即時実行できるため、個人健康情報（PHI）の漏洩リスクが原理的にゼロ。

電子カルテ端末の非力なブラウザ環境でもUI描画（60fps / 16msフレーム）を一切阻害しないバックグラウンド処理が可能。

2. オフラインAI端末におけるHID/プリンタ方式 運用ガイドライン
規格・ガイドラインの要点:

電子カルテのRDBMSへの直接接続（ODBC/JDBC/SQL）やAPI非公開システムへのフック（DLLインジェクションや非公式ドライバ導入）を行わず、OS標準ドライバで認識される「USB HID（Human Interface Device / キーボード）」または「仮想プリンタポート」を介した入出力を公認。

「電子カルテシステム自体の改変を行わない」「端末OSから見て物理キーボードと同等に扱われる」ため、医療機器認証（SaMD）の改修申請や院内情シスによるベンダー保証喪失リスクを回避。

臨床現場における意義:

ベンダーロックインが強く外部接続が拒絶されやすい電子カルテ環境に対し、「物理入力補助デバイス」という建前で合法・安全に導入可能なデファクトスタンダードの確立。

徹底的弱点・反論・見落とされがちな前提条件（Critical Challenge）
形態素解析と文脈依存性のギャップ:

単語分割（「急性」「虫垂炎」）とコードマッピング（ICD-10: K35.8）ができても、主訴が「右下腹部痛あり、急性虫垂炎は否定的」だった場合、単純なキーワード抽出では「病名：急性虫垂炎」を誤検出する（Negation Detectionの欠如）。SLM（小型言語モデル）やルールベースの否定表現フィルターをWasmの前後に挟まない限り、単体での直接運用は危険。

OS/IME依存のテキスト挿入事故:

HIDキーボード送信は、ホストPC側のIME（MS-IME、ATOK等）の状態（ローマ字入力モード、直接入力モード）に完全に依存する。Unicode文字を直接送り込む仮想HID（Raw HID/Altコード方式）やクリップボード経由の安全なペーストエミュレーション（Ctrl+Vシーケンス）を綿密に設計しないと、カルテ上で「kinnkyuuzennkai」のようなローマ字化けが多発する。

Mindsガイドラインの法的位置づけ:

Mindsのガイドラインはあくまで治療方針の参考情報であり、個別患者の背景因子（併存疾患、アレルギー等）をすべて網羅しているわけではない。ガイドラインをトリガーにした処方サジェストは、処方支援システム（CDSS）とみなされ、意図せず医療機器プログラム（SaMD）の規制領域に踏み込む境界リスクを孕む。

①「胃 → 亜」の化け原因（CP932/Shift_JISのオフセットと先頭ゼロ）
WindowsのANSIコードページ（CP932）において、亜 はShift_JISコードで 0x889F（10進数：34975）、胃 は 0x88C3（10進数：35011）です。
ログにある「034995」という数値は、文字コードの参照テーブル境界やバイトオフセットの計算ズレにより、別のグリフ（あるいは「亜」近傍のコード）に誤マッピングされています[cite: 4]。また、先頭の「0」の有無でOEMコード（CP437等）とANSIコード（CP932）の解釈がOSカーネル内で分岐するため、5桁コード送出時のゼロプレフィックス制御が厳密でなければ化けが発生します。

// File: src/workers/vibrato.worker.ts
// 説明: Vibrato WasmをWeb Worker内で起動し、Zstandard圧縮辞書をIndexedDBから
//       オンデマンド/オフラインロードして0.5ms以内で形態素解析を実行するワーカー
// =============================================================================

import initVibrato, { Tokenizer } from 'vibrato-wasm';
import { decompress } from 'fzstd'; // ピュアJS/Wasm対応の高速Zstandard伸張ライブラリ

// -----------------------------------------------------------------------------
// 型定義
// -----------------------------------------------------------------------------
export interface MorphToken {
  surface: string;
  feature: string;
  pos: string;       // 品詞大分類 (例: 名詞, 動詞)
  subPos: string;    // 品詞細分類 (例: 一般, 固有名詞)
  reading: string;   // 読み (カタカナ)
}

export type WorkerRequest =
  | { type: 'INIT'; payload: { dictUrl: string; cacheKey?: string } }
  | { type: 'TOKENIZE'; id: number; payload: { text: string } };

export type WorkerResponse =
  | { type: 'INIT_SUCCESS' }
  | { type: 'INIT_ERROR'; error: string }
  | { type: 'TOKENIZE_SUCCESS'; id: number; tokens: MorphToken[]; durationMs: number }
  | { type: 'TOKENIZE_ERROR'; id: number; error: string };

// -----------------------------------------------------------------------------
// IndexedDB キャッシュ層 (オフライン永続化)
// -----------------------------------------------------------------------------
const DB_NAME = 'donguri_nlp_cache';
const DB_VERSION = 1;
const STORE_NAME = 'dict_blobs';

function openDatabase(): Promise<IDBDatabase> {
  return new Promise((resolve, reject) => {
    const request = indexedDB.open(DB_NAME, DB_VERSION);
    request.onupgradeneeded = () => {
      const db = request.result;
      if (!db.objectStoreNames.contains(STORE_NAME)) {
        db.createObjectStore(STORE_NAME);
      }
    };
    request.onsuccess = () => resolve(request.result);
    request.onerror = () => reject(request.error);
  });
}

async function getCachedDictionary(key: string): Promise<ArrayBuffer | null> {
  const db = await openDatabase();
  return new Promise((resolve, reject) => {
    const tx = db.transaction(STORE_NAME, 'readonly');
    const store = tx.objectStore(STORE_NAME);
    const request = store.get(key);
    request.onsuccess = () => resolve(request.result || null);
    request.onerror = () => reject(request.error);
  });
}

async function setCachedDictionary(key: string, data: ArrayBuffer): Promise<void> {
  const db = await openDatabase();
  return new Promise((resolve, reject) => {
    const tx = db.transaction(STORE_NAME, 'readwrite');
    const store = tx.objectStore(STORE_NAME);
    const request = store.put(data, key);
    request.onsuccess = () => resolve();
    request.onerror = () => reject(request.error);
  });
}

// -----------------------------------------------------------------------------
// 辞書の取得・展開パイプライン
// -----------------------------------------------------------------------------
async function loadAndDecompressDictionary(
  dictUrl: string,
  cacheKey: string = 'vibrato_system_dict_zst'
): Promise<Uint8Array> {
  let compressedBuffer = await getCachedDictionary(cacheKey);

  if (!compressedBuffer) {
    const res = await fetch(dictUrl);
    if (!res.ok) {
      throw new Error(`辞書のダウンロードに失敗しました: HTTP ${res.status}`);
    }
    compressedBuffer = await res.arrayBuffer();
    // オフライン動作用に圧縮状態のままIndexedDBへ永続化（ストレージ節約）
    await setCachedDictionary(cacheKey, compressedBuffer);
  }

  // Zstandard (zstd) バイナリをインメモリ展開
  const compressedBytes = new Uint8Array(compressedBuffer);
  const decompressedRaw = decompress(compressedBytes);
  return decompressedRaw;
}

// -----------------------------------------------------------------------------
// 形態素解析ワーカーのステート管理
// -----------------------------------------------------------------------------
let tokenizerInstance: Tokenizer | null = null;

self.onmessage = async (e: MessageEvent<WorkerRequest>) => {
  const message = e.data;

  switch (message.type) {
    case 'INIT': {
      try {
        // 1. Wasmモジュール初期化
        await initVibrato();

        // 2. 辞書バイナリ展開取得
        const dictBytes = await loadAndDecompressDictionary(
          message.payload.dictUrl,
          message.payload.cacheKey
        );

        // 3. Vibrato Tokenizerインスタンス生成（文字単位ダブル配列/連接表の構築）
        tokenizerInstance = new Tokenizer(dictBytes);

        const response: WorkerResponse = { type: 'INIT_SUCCESS' };
        self.postMessage(response);
      } catch (err: any) {
        const response: WorkerResponse = {
          type: 'INIT_ERROR',
          error: err?.message || String(err),
        };
        self.postMessage(response);
      }
      break;
    }

    case 'TOKENIZE': {
      const { id, payload } = message;
      if (!tokenizerInstance) {
        const response: WorkerResponse = {
          type: 'TOKENIZE_ERROR',
          id,
          error: 'Tokenizerが初期化されていません。先にINITを実行してください。',
        };
        self.postMessage(response);
        return;
      }

      try {
        const startTime = performance.now();

        // Vibrato Wasmによる高速Viterbiラティス探索 (定常時 0.2〜0.5ms)
        const rawTokens = tokenizerInstance.tokenize(payload.text);
        const durationMs = performance.now() - startTime;

        // 打鍵コンパイラ・MedPilotが必要とする形式へ構造化
        const tokens: MorphToken[] = new Array(rawTokens.length);
        for (let i = 0; i < rawTokens.length; i++) {
          const t = rawTokens[i];
          const features = t.feature.split(',');
          tokens[i] = {
            surface: t.surface,
            feature: t.feature,
            pos: features[0] || '',
            subPos: features[1] || '',
            reading: features[7] || '',
          };
        }

        const response: WorkerResponse = {
          type: 'TOKENIZE_SUCCESS',
          id,
          tokens,
          durationMs,
        };
        self.postMessage(response);
      } catch (err: any) {
        const response: WorkerResponse = {
          type: 'TOKENIZE_ERROR',
          id,
          error: err?.message || String(err),
        };
        self.postMessage(response);
      }
      break;
    }
  }
};

// File: src/services/VibratoClient.ts
// 説明: メインスレッド（PWA）側からWeb Workerを非同期呼び出しするクラスタ
// =============================================================================

import type {
  MorphToken,
  WorkerRequest,
  WorkerResponse
} from '../workers/vibrato.worker';

export class VibratoClient {
  private worker: Worker;
  private requestId = 0;
  private pendingCallbacks = new Map<
    number,
    {
      resolve: (value: { tokens: MorphToken[]; durationMs: number }) => void;
      reject: (reason: any) => void;
    }
  >();
  private isInitialized = false;

  constructor() {
    this.worker = new Worker(
      new URL('../workers/vibrato.worker.ts', import.meta.url),
      { type: 'module' }
    );
    this.worker.onmessage = this.handleMessage.bind(this);
  }

  private handleMessage(event: MessageEvent<WorkerResponse>) {
    const data = event.data;

    if (data.type === 'TOKENIZE_SUCCESS') {
      const handler = this.pendingCallbacks.get(data.id);
      if (handler) {
        handler.resolve({ tokens: data.tokens, durationMs: data.durationMs });
        this.pendingCallbacks.delete(data.id);
      }
    } else if (data.type === 'TOKENIZE_ERROR') {
      const handler = this.pendingCallbacks.get(data.id);
      if (handler) {
        handler.reject(new Error(data.error));
        this.pendingCallbacks.delete(data.id);
      }
    }
  }

  /**
   * Zstandard圧縮辞書バイナリのロードおよびWasmエンジン初期化
   * @param dictUrl 配布先URL (.dic.zst)
   */
  public init(dictUrl: string): Promise<void> {
    return new Promise((resolve, reject) => {
      const initHandler = (e: MessageEvent<WorkerResponse>) => {
        if (e.data.type === 'INIT_SUCCESS') {
          this.isInitialized = true;
          this.worker.removeEventListener('message', initHandler);
          resolve();
        } else if (e.data.type === 'INIT_ERROR') {
          this.worker.removeEventListener('message', initHandler);
          reject(new Error(e.data.error));
        }
      };

      this.worker.addEventListener('message', initHandler);
      const req: WorkerRequest = {
        type: 'INIT',
        payload: { dictUrl },
      };
      this.worker.postMessage(req);
    });
  }

  /**
   * 0.5ms形態素解析の実行
   */
  public tokenize(text: string): Promise<{ tokens: MorphToken[]; durationMs: number }> {
    if (!this.isInitialized) {
      return Promise.reject(new Error('Vibrato is not initialized yet.'));
    }

    const id = ++this.requestId;
    const req: WorkerRequest = {
      type: 'TOKENIZE',
      id,
      payload: { text },
    };

    return new Promise((resolve, reject) => {
      this.pendingCallbacks.set(id, { resolve, reject });
      this.worker.postMessage(req);
    });
  }

  public terminate() {
    this.worker.terminate();
    this.pendingCallbacks.clear();
  }
}

   - 漢字は CP932 (Shift_JIS) 10進コードに基づく `Alt + Numpad` シーケンスを厳格生成すること[cite: 3, 4]。
3. 画面非破壊性の徹底 (カルテ誤爆防止):
   - F5キーなどの画面リロードを誘発するキーは使用厳禁[cite: 1, 3]。
   - Alt抜けによる「ファイルメニュー誤爆」を物理的に遮断するディレイ（11ms）とステートマシンを実装すること[cite: 1, 2, 4]。
4. クライアントサイド完結 (PHI保護):
   - 外部サーバーへの通信は行わず、形態素解析（Vibrato Wasm）および推論はすべてブラウザサンドボックス内で完結させること[cite: 5]。

## 3. モジュール別 実装要件

### A. ハードウェア層: ESP32-S3 ファームウェア (PlatformIO / Arduino / TinyUSB)
- USB Composite デバイス構成:
  - Device Descriptor: USB HID Keyboard (Class 03h) ＋ USB Printer (Class 07h)[cite: 1]
  - 病院DLP監視ソフト（SKYSEA等）に一般周辺機器として認識させ、ストレージ（MSC）は露出させない[cite: 2]。
- タイピングステートマシン (Alt抜け・文字化け完全防止):
  - Alt+Numpad シーケンス:
    1. `KEY_LEFT_ALT` 押下保持
    2. 11ms ディレイ[cite: 2]
    3. テンキーの各数字スキャンコード (Keypad 0〜9) を順次打鍵（押下 11ms ➔ 解放 11ms）[cite: 2, 3]
    4. `KEY_LEFT_ALT` 解放
    5. 11ms ディレイ ➔ 状態クリアのためダミーの Shift キー空打ち（Altメニュー誤爆の物理遮断）[cite: 2, 4]
  - カタカナ・英数打鍵:
    - ローマ字打鍵 ➔ F7（全角カタカナ変換） ➔ Enter
    - ASCII打鍵 ➔ F10（半角変換） ➔ Enter
- BLE (Web Bluetooth) 通信:
  - Nordic UART Service (NUS) またはカスタムUUIDを用いた双方向キャラクタリスティック。
  - 仮想プリンタ受信バッファをBLE経由でPWAへストリーミング送出[cite: 2]。
  - PWAから受信した打鍵パケット列をFIFOリングバッファに積載し、上記ステートマシンで逐次送出。
- 0.96インチLCD表示:
  - BLE接続状態（DISCONNECTED / CONNECTED）、スプール状況、送出文字数をリアルタイム描画。

### B. フロントエンド層: PWA / Web Worker (TypeScript / Vite / Tailwind)
- Web Bluetooth Persistent Auto-Reconnect:
  - 初回ペアリング後、デバイスIDをIndexedDBに保持。2回目以降は `navigator.bluetooth.getDevices()` によるサイレント自動再接続[cite: 2]。
- 形態素解析ワーカー (Web Worker 隔離):
  - Rustネイティブ Wasm (`Vibrato`) を採用し、メインスレッドのUI描画（60fps）を阻害しないこと[cite: 5]。
  - 辞書配備: Zstandard圧縮辞書 (`.dic.zst`) を初回Fetchし、IndexedDBへ永続化（完全オフライン対応）[cite: 5]。
  - 0.5ms以内でテキストをパースし、品詞・読み・表記種別を抽出[cite: 5]。
- 形態素駆動型 打鍵トランスパイル・エンジン:
  - 解析トークンを以下の打鍵ブロックへ自動分類:
    1. 漢字混じり・記号 ➔ `[ALT_BLOCK]` (CP932 10進数 + Numpad)[cite: 1, 3]
    2. カタカナ（薬品名・外来語） ➔ `[F7_BLOCK]` (ローマ字打鍵 + F7 + Enter)
    3. 数値・単位・半角英数 ➔ `[F10_BLOCK]` (直接入力 + F10 + Enter)
    4. 未知語トークン ➔ `[ALT_SAFE_BLOCK]` (安全縮退: 1文字ずつのAltコード入力)[cite: 1, 3]
  - 生成されたバイナリパケットを `Uint8Array` ゼロコピー転送でBLEキャラクタリスティックへ書き込み。

## 4. 出力成果物の指定
以下の構成で、ビルド可能かつ欠落のないソースコードファイルを順次生成してください。
1. `firmware/src/usb_descriptors.c`: TinyUSB複合デバイス（HID + Printer）の記述子定義[cite: 1]
2. `firmware/src/typing_engine.cpp`: 11msディレイ・Alt誤爆防止ステートマシン実装[cite: 2, 4]
3. `pwa/src/workers/vibrato.worker.ts`: IndexedDBキャッシュ・Zstd展開・Vibrato Wasm形態素解析ワーカー[cite: 5]
4. `pwa/src/services/KeyStrokeCompiler.ts`: 形態素トークンからAlt/F7/F10バイナリを生成するトランスパイラ
5. `pwa/src/services/BleManager.ts`: 永続自動再接続を備えたWeb Bluetooth通信クライアント[cite: 2]
プロンプト活用の運用テクニック
一括生成させず、モジュール単位で確定させる:
Google Antigravity 2 に対し、まずは「要件の理解とアーキテクチャ確認」を行わせ、その後に firmware/src/typing_engine.cpp（ハードウェア低レイヤー）➔ pwa/src/services/KeyStrokeCompiler.ts（トランスパイラ）の順で段階的に出力させることで、コード省略（Lazy Coding）を防ぎます。
